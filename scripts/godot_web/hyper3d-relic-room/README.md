# Relic Courier / 遗迹信使

Native Godot 4.6.3 GL Compatibility source for `hyper3d-relic-room`. Open
`game/project.godot`; no API credential or DCC adapter is required to play.
Source authoring, typed host operations and real input are distinct evidence
scopes. Final acceptance lives in the case's dated validation record.

The current ARPG leaves a safe archive court for the warden grove: fight,
recover drops, equip a focus and blade, unlock Arc, then return prepared.
A real hinged chest provides one-time loot and saved progress. WASD/arrows
move, Space dashes, F/left click attacks, Q casts unlocked Arc, E interacts,
I opens the bag and Escape pauses. Native English/Chinese and optional touch
controls share the same project. The declared layout boundary is landscape,
960 × 600 and above. Licensed CC0 effects and a native SFX switch are included;
subjective listening remains a separate pending gate.

`export.py` creates a fresh isolated official Web export with pinned 4.6.3
templates. `prepare.py` stages its exact verified pack, four existing shared
runtime files and a small adaptation of Dawnkeep's lifecycle/readiness shell.
Neither script certifies actual native or browser input. No game commands are
sent through the publication bridge; reset reloads the real engine.

Fresh checkouts and exact-head CI archives use the existing
`python scripts/godot_web/materialize_runtime.py` preparation step before
validation/build. It also verifies five fixed Hyper3D LFS data files. Complete
matching files require no network; only missing files or matching LFS pointers
are fetched from this repository at the exact Git HEAD (or CI PR-head/commit
SHA in an archive). Size and SHA-256 are checked before atomic replacement;
unexpected existing bytes are rejected. The browser continues to load the
same-origin film and PCK; this adds no external runtime URL or executable code.
