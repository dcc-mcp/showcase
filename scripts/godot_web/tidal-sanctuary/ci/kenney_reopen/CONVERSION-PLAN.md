## Independent-review corrections

1. Material storage maps are no longer repeated in each graph. The witness stores a bounded table of JSON material records, each keyed by the SHA-256 of its exact UTF-8 content. Graphs hold references; the host verifies and expands them before exact comparison. A read-only pass over all four actual imports and baselines estimates the complete graph/table witness before creating the candidate directory or saving any candidate, reserving 64 KiB for metadata/path differences. Tests include 18 distinct material maps with 150 added properties each; deduplication remains below the unchanged 1 MiB witness budget.
2. Native cleanup now closes/flushed logs and runs the engine-error check again against the final editor log. A shutdown-only engine error makes the session fail and prevents the second session.
3. `tscn_grammar.py` deliberately recognizes only this converter's bounded property/value grammar: numeric transforms/colors, explicit material scalars/names, known ArrayMesh surface data, and local SubResource references. Unknown node flags such as `visible` or `cast_shadow`, properties, sections, identifiers and constructor expressions are rejected before independent instantiation. This is a conservative acceptance grammar, not a claim that arbitrary rejected text would execute in Godot; no unverified exploit claim is made. All four actual pinned baseline files pass it.
4. The coordinator handles SIGTERM/SIGINT, forwards cancellation to the owning Python session, and waits for that session's actual editor/server/Xvfb teardown. It does not kill only Python and orphan native children. Repeated cancellation during teardown is suppressed. If cleanup stalls, the coordinator remains blocked waiting; it does not advance to independent reopen or claim success. The session likewise suppresses repeated teardown signals. Mocked cancellation tests verify forwarding, waiting, retained cleanup evidence and no second launch.

These are offline fixes only. Actual engine parsing, conversion, independent reopen, cancellation behavior and shutdown logs still require a later authorized native run.


The final cleanup-edge revision also masks coordinator cancellation across Python process acquisition, restoring the mask only after the child reference is owned inside the cleanup-covered try. The session unmasks after installing its own handlers. Native editor/Xvfb process acquisition instead defers cancellation until its ownership reference is assigned, avoiding inherited blocked signals in those native executables. Pre-shutdown process state and actual requested terminate/kill actions are recorded; an already-dead process or an unrequested terminal signal fails cleanup even if no engine-log token explains the exit.
