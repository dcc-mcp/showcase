# Dawnkeep bounded production research

Date: 2026-10-18. Scope: original single-player hero-defense vertical slice,
not a recreation of protected Warcraft or League assets or a canonical old map.

## Gameplay references and deliberate selection

The user named the historical Warcraft III custom-map family 守卫雅典娜 / 守护雅典娜.
A 2020 player recording explicitly identifies Standard 9.0 and separately lists an
alternate variant, so there is no claim that all versions have one rule set:
https://www.bilibili.com/video/BV18a4y1i7zd/
A separate Standard 9.0 solo player record discusses starting equipment,
experience/stat books and later enemy waves:
https://www.bilibili.com/video/BV1ui4y1N7zj/
These are player records, not an authoritative original design document. No map,
models, music, footage or other protected game assets were copied.

The original adaptation prioritizes a controllable hero, automatic close combat,
three active abilities, XP/levels, an equipment shop, eight authored enemy waves,
respawn pressure, a vulnerable shrine and a final boss. Four tower types are
supporting choices rather than the main character. One replayable 8-wave map is
in scope. Multiplayer and exhaustive historical-map reconstruction are not.

## Art research

- Riot's Clarity in League: readable silhouette, facing, effect hierarchy.
  https://www.leagueoflegends.com/en-us/news/dev/clarity-in-league/
- Riot's graphics-pipeline overview: painted/baked static surface lighting and
  soft grounding shadows. Inspiration only; no artwork copied.
  https://www.riotgames.com/en/news/trip-down-lol-graphics-pipeline
- Godot 4.6 recommends glTF 2.0 for interoperable 3D scene exchange.
  https://docs.godotengine.org/en/4.6/tutorials/assets_pipeline/importing_3d_scenes/available_formats.html

Coherent selected candidates: author's free KayKit Forest, Adventurers 2.0,
Skeletons 1.1 and Character Animations 1.1, all explicitly CC0. Paid terrain,
extra characters and paid boss models are excluded. Actual acquired versions,
source URLs/hashes and selected files are recorded separately by the art recipe.
https://kaylousberg.itch.io/kaykit-forest
https://kaylousberg.itch.io/kaykit-adventurers
https://kaylousberg.itch.io/kaykit-skeletons
https://kaylousberg.itch.io/kaykit-character-animations

Quaternius Stylized Nature MegaKit (CC0 free subset but larger package and
paid-only source shaders), Ultimate Fantasy RTS (CC0 buildings), Poly Haven
(CC0 but photorealistic high-frequency textures do not suit this composition).
https://kenney.nl/assets/tower-defense-kit
https://quaternius.itch.io/stylized-nature-megakit
https://quaternius.com/packs/ultimatefantasyrts.html

Original assets fill the clear gap: the contiguous floating terrain, sandstone
lanes, ornate living-crystal shrine and four distinct defensive structures.
Blender-native script authoring is labelled honestly; Godot typed MCP scene and
script authoring, save/restart/reopen are a separate measured pipeline.

## Reuse gate and installed capabilities

The verified official Core workflow source contains dcc-mcp-production-reuse/v1:
https://github.com/dcc-mcp/dcc-mcp-core/blob/main/crates/dcc-mcp-gateway/src/gateway/native_resources/agent_workflows.md
Read on 2026-10-18, source SHA 987379bb1dfbc68eefc7159652f87649676a3992.
The repo's production skill, existing pinned Godot host, existing official
adapter/Core authoring harness and source inventory were inspected before
production. The local host is actual Godot 4.6.3 official and Blender 4.3.2.
No new custom addon/runtime is created. Existing Godot DCC-MCP packages are
isolated and pinned, and actual typed-call probe receipts distinguish tooling
verification from finished-game acceptance. Blender extension-store discovery
and exact selected asset receipts are retained with art documentation.

## Music selection

Author-uploaded CC0 source pages:
- Determined Pursuit, Emma_MA, 2017: explicitly loopable orchestral battle music.
  https://opengameart.org/content/determined-pursuit-epic-orchestra-loop
- The Field of Dreams, pauliuw, 2010: fantasy/cinematic instrumental theme.
  https://opengameart.org/content/the-field-of-dreams

Full source recording and Ogg derivatives have recorded hashes. Original sound
feedback uses deterministic shaped sine chords generated by main.gd. No Warcraft,
League or other commercial-game music or sound effect is used. Technical bus
measurement, complete decode, actual rendered playback and subjective listening
are separate review stages; none is inferred from file presence.
