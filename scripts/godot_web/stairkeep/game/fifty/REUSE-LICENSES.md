# First-chapter reuse and rights

This increment extends the existing Stairkeep Godot project. It does not replace
it with another template or describe the official isometric demo as a complete
tower game. The new runtime, data, original narrative and tests use the repository
MIT terms. No reference-game maps, dialogue, artwork or software were acquired.

[reuse_manifest.json](reuse_manifest.json) records the actual local hashes checked
on 2026-10-25. All 10 existing Kenney PNGs and five pinned Godot demo files match
their retained source manifests. The Kenney CC0 license, official demo MIT notice,
source versions and modifications remain in their original project paths.
The original pack-label discrepancy remains visible in the historical source
record; it is not rewritten as a fresh acquisition.

The bounded discovery consulted the verified Core
[`dcc-mcp-production-reuse/v1` guide](https://github.com/dcc-mcp/dcc-mcp-core/blob/main/crates/dcc-mcp-gateway/src/gateway/native_resources/agent_workflows.md#production-reuse-gate)
and the official Godot Asset Library. Its
[Godot 4 isometric demo listing](https://godotengine.org/asset-library/asset/2718)
fits the existing component approach; the already pinned matching 4.7 upstream
files are retained. The Godot 3.5 listing and a 3D city-builder starter are not
suitable replacements. No additional package was downloaded, installed or run.

The existing world renderer and icon code are reused unchanged. The missing
capabilities are the typed campaign events, runtime D4/state mapping, independent
save identity and original resource-puzzle content; these are the focused new
implementation. No new font or audio pack is introduced. English preview text
avoids a new bundled-font dependency; Chinese/Web glyph and audio acceptance are
not claimed.

Current tools do not expose a live gateway resource/marketplace surface, and the
prior interactive input gate remains denied. This run uses only the originally
authorized Godot headless CLI route. It does not claim a new typed MCP import,
native pixel review, real input or browser acceptance. Existing concept art is
the design reference, not a screenshot of the new chapter.
