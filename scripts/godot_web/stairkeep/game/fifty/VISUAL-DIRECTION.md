# 阶塔 / Stairkeep：首十层视觉方向

阶塔 / Stairkeep 保持既有临时品牌与 slug，可改名；「潮痕信塔 / Tide-mark
Signal」仅为首章原创视觉、叙事副题，不建立新项目或 Library 身份。
目标为 50 层；本轮只制作 1–10 层切片，11–50 层未制作。
本说明先确定视觉与信息层级；新增 Godot 场景是待验收预览，尚无本轮
GUI、渲染截图、真实键鼠或浏览器验收。不把 headless 实例化当成视觉通过。

## 延续已经存在的真实游戏美术

采用既有等距小景：暖砂岩可走地面、深靛蓝空域与台基、青色楼梯、黄铜
资源与门锁。直接复用 `res://scripts/world.gd`、现有 Kenney PNG、官方
Godot isometric TileSet 与静止 goblin 动画；不改旧三层主场景、素材或默认入口。
新 view 只薄扩展 NPC 和事件标记，继续使用同一个 TileSet 投影、Y 排序和
世界点击逻辑。游戏地图由真实 Godot 节点及现有纹理绘制；不是 HTML 线框。

底色 `#101f2c`，砂岩 `#e8c48a`，正文 `#f2e9d8`，次要说明 `#91a6af`，
楼梯／焦点 `#7bcac8`，损耗／不能获胜 `#e5968d`。青色不同时承担金币或
敌对警告。可走层保留暖色，墙和台基保持冷色，避免对地面调色掩盖可通行性。
各区域通过低饱和环境色、对象组合、空间轮廓和命名区分，资源语义色不变。

## 十层区域意象

这是首批原创关卡的美术执行约束，具体坐标、门槛、奖励与剧情效果以
`fifty/data/content.json` 和新 runtime 为准；view 不另造资源或效果。

| 层 | 区域 | 可读小景意象与已许可素材用法 | 需要在画面里读到的目的 |
|---|---|---|---|
| 1 | 归潮门厅 | 砂岩门廊与一张测绘桌；NPC 采用既有人物纹理与黄铜记号 | 测绘员岚绘、向上探索、稍后带铜签回访 |
| 2 | 绳桥库 | 狭长暖石桥面、木箱与桶的库房节奏；不新增绳索贴图 | 桥／铁梯连接与资源支路 |
| 3 | 回声索室 | 较冷的石面、短壁围出的回声室；黄铜事件牌标识缺角铜签 | 取得铜签后返回 1 层，不是继续盲爬 |
| 4 | 双庭水闸 | 成对平台与两条连接，深蓝负空间表现水闸分隔 | 两桥路线与钥匙消耗的区别 |
| 5 | 盐封档案 | 苍白砂石、稀疏立柱与黄铜档案事件牌 | 蓝门、档案线索、有限装备；不把装饰当宝物 |
| 6 | 绕潮盘道 | 台基围出绕行轮廓；青色楼梯始终优先可读 | 螺旋回廊方向与返回路径 |
| 7 | 守灯人廊 | 细长暖灯廊与守灯人 NPC；既有光晕及人物纹理 | 归还档案线索、一次补给的已兑现状态 |
| 8 | 三径蓄池 | 三条石径之间留下冷色空域；桶／柱只作稀疏装饰 | 三径资源取舍，不用装饰遮门和敌人 |
| 9 | 四翼校准室 | 四翼空间轮廓，中心低墙与重复柱节奏 | 分支代价和回访目标，不靠换色冒充新机制 |
| 10 | 无火信台 | 最高处的青色梯与黄铜信号事件标记；保留靛蓝空间 | 点亮信号仅完成此切片；50 层完整游戏尚未完成 |

## 原生 HUD 与交互层级

使用独立 `fifty/view/preview.tscn`。旧 `main.gd` 固定了三层规则与标题数组，
直接继承会连带旧 reset/save 和楼层索引。因此 presenter 采用 composition：
复用 world、图标与视觉 token，所有状态变化委托新 runtime，不复制战斗公式。

1280×800 是首轮设计基准。顶部固定品牌／临时名称、制作范围和六项资源，
世界视窗占主区域，右侧为原生 `TabContainer`：现场检查、图鉴、线索／回访。
正文使用现有字体路径／默认字形能力，不下载新字体；首轮可操作文案使用
英文，NPC 对白和线索薄页直接显示原创内容中的原中文文本，不在 view 重写
成另一套剧情。中文、Web 字形覆盖未验，系统 fallback 不构成字形验收。

- 模式面板无预选项：Classic 与 Practice 必须主动选其一，开始及读档在
  未选择时禁用。模式名称与实际限制常驻显示，不用一个不明含义的“继续”。
- Classic／Practice 的重置、失败、检查点和存档行为来自 runtime；view 不
  增加 HP、金币、钥匙、库存、地图重置捷径或练习模式外的回档能力。
- 门面板显示匹配钥匙和一次消耗；商店逐项显示价格、库存与 runtime 可否
  购买结果；怪物面板和图鉴均调用 runtime 同一战斗预览。
- NPC／事件用独立黄铜身份牌及人物／事件形状区分，不伪装成可拾取钥匙。
  线索薄页显示回访对象、所在层、未完成／已完成状态；不泄露未制作层内容。
- Save、Load、Restart、Mode 为真实 Button；重开和换模式先显示原生确认
  面板，明确当前局将替换与存档是否保留。载入不得静默切换选定模式。
- 可见键盘焦点、44px 最小按钮高度；模态遮挡世界输入。布局由 Container
  排序，地图在后续帧按世界视窗矩形适配，不强行覆盖 Container 子项位置。
- 10 层终点显示“Slice complete / 10 authored of 50 planned”，不显示完整
  50 层通关、数小时体验或未经测试的视觉质量保证。

路径同样未获恢复。字形覆盖为 `not-tested`。本轮只做静态作者检查，root
统一运行的 headless 结果另记，不反填成像素或输入通过。
