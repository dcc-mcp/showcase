# 体验04：动作期间的GUI焦点归属

静态复核 `91c7cad` 发现：`_commit` 在每次动作动画结束后无条件
`gui_release_focus()`。连续点地路径期间，用户可以点入图鉴ItemList；
其新焦点会被动作结束清掉，之后方向键可能转入地图。

本轮修正限定自动归还对象：仅实际动作按钮的发起焦点可以在动作完成后
归还世界输入，而且必须仍有效、当前焦点仍是同一按钮。动画期间新取得的
ItemList／Tab焦点予以保留。后续自动路径格不能把浏览用的Control误当成
该格的发起按钮。起始无焦点或发起控件已销毁也不能清掉新焦点。

键盘控制器及70／240／180ms合同保持体验03版本；GUI获焦仍会硬取消持键与
待执行意图，焦点归还不会重新armed。地图点击和显式关闭模式窗的既有焦点
归还仍是用户主动操作，不属于异步动作结束后的自动夺取。

新增静态接线检查要求焦点捕获先于规则调用／await、只接纳动作按钮、完成时
检查有效性和同一owner，防止恢复无条件释放。该检查不是Godot执行或真实
焦点事件验收。原生后必须走：长路径中点入图鉴→连续多个路径格完成→方向键
仍导航图鉴；另测Tab、发起按钮、空owner、被销毁owner、Esc及窗口失焦。
