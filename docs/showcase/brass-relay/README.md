# Brass Relay / A four-bar study

A brass input flywheel drives an oxblood coupler and a silver rocker above an ivory instrument base. FreeCAD parametric parts, three Blender scenes and a corrected Kdenlive editor project keep the illustrated mechanism inspectable and editable.

## What is editable

- 13 separate FreeCAD parameter/boolean parts, with STEP and STL exchanges
- Three Blender native scenes for the hero, plan and animation views; each retains the scene, cameras, text, materials and original keys
- A 432-frame Kdenlive project using 98 unchanged relative PNGs and 390 native Dynamic Text filters

The compact source package contains native CAD and Blender scenes, the corrected timeline and small viewing previews. Its editor timeline requires the unchanged media folder from the full native package or the original delivered media. The full package retains all 98 timeline images and the original native masters. Install DejaVu Sans separately; the package includes its scoped upstream notice, with no font binary.

## What was measured

FreeCAD typed MCP calls authored the geometry; Blender typed MCP calls built and keyed the illustration; Kdenlive typed MCP calls authored and qualified the timeline. CAD dimensions are millimetres, with Blender illustration coordinates equal to CAD millimetres divided by 20. The four link lengths are 70, 25, 80 and 50 mm. Sampled native hinge readback reached a maximum error of 0.000007226413753188325 mm.

There are 97 endpoint-inclusive keyed poses and 96 distinct motion renders. The four-second cycle plays twice within an 18-second, 24 fps film with editorial stills and captions. All 432 frames were compared in accepted-output and moved-package headless proofs. The video pictures span 18 seconds; the silent AAC/container spans 18.005 seconds.

The three exact packaged BLENDs have native save/reopen readback and full-production reference pixel proof. All 13 final FCStd presentation copies have native tree, geometry, placement and view readback. The separate visual FreeCAD first-open observation covers a representative flywheel proof copy, not every final packaged part.

The current editor's native GUI evidence covers untouched Save Copy/reopen, nine representative project-preview positions, all 390 serialized identities/text/style values, and all 432 same-display RGB/RGBA frames and MP4 bytes. Visual control inspection covers only the two closing stack entries and the first closing text field. Other pairs, the second field and reopened controls were not visually inspected. Parameter editing/Undo and source-monitor qualification are excluded from this final gate. The GUI comparison movie and web film retain separate identities.

## Boundaries

This is sampled prescribed kinematics. It does not establish dynamics, manufacturing tolerances, stress, load capacity, safety, continuous collision freedom, cross-machine rendering equality or a seamless pixel loop. FreeCAD parts remain separate; the assembled view is in Blender. The earlier look-development image has a different camera and resolution, so it is not a matched-pose comparison.

The public evidence contains selected recorded calls and results. Private diagnostics are omitted with hashes; paths and execution identifiers are removed or aliased. The archive assembly used existing qualified sources; it performed no new native save, host launch, rendering or media retouching. Original receipts and delivered files are preserved separately. Original artwork and native/source assets have the rights reservation in LICENSES.md; the site-code MIT license does not license them.
