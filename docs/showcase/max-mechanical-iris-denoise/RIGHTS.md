# Rights and software boundaries

The mechanical scene uses original procedural geometry and native materials; no external artwork, image textures, generated bitmap art, music or purchased models are included. Original scene, renders and case evidence retain their existing rights; the website license does not grant extra rights in these artifacts.

3ds Max and Arnold/Noice remain Autodesk products. Blender is separately installed GPL software, OIDN is the denoising algorithm supplied by Blender, and the media-enhance orchestration source is MIT. No proprietary backend, Blender binary, model weight or installer is bundled here. Existing host license settings were retained; no new entitlement or trial terms were accepted. Independent license-checkout evidence is not claimed.

Native project files and raw execution logs remain private pending distribution sanitization. Public documents contain selected measurements and hashes; they are not raw transport receipts. Model and reasoning-effort attribution are unknown; source repository identity is separate from backend algorithm identity.
