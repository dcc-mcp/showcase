背景层，以及核过 CC0 来源的铜剑 GLB。尚未执行 Nuke 或 Blender，未交付原生

或剩余额度，记录为 unknown；Codex 只负责编排。不新增 Hyper3D 生成、付费、账户
切换或依赖安装。

再仅乘 RGB 并保留底图 alpha，避免缩放后的透明黑色区域把实拍压黑。
