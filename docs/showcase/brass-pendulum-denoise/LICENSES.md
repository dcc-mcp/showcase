# Rights and scope

The original Brass Pendulum scene, rendered imagery, video, scene recipe and
case-specific evidence and documentation in this directory are provided for
public inspection with rights reserved. Publication does not add an MIT grant
or authorize redistribution or commercial use of the original artwork.

The repository's shared website code and existing documentation keep their
existing licenses. Blender, Open Image Denoise, FFmpeg and DCC-MCP retain their own upstream
licenses. No third-party images, external textures, soundtrack or AI-generated
bitmap assets are included in this case.

The public native project is a path-cleaned derivative of the actual production
scene. Its provenance, the original hash and the limits of equivalence checking
are recorded in native-inspection.json. The dcc-media-enhance processing implementation
is not bundled here; the public filter and encoding recipe can be reviewed
independently.
