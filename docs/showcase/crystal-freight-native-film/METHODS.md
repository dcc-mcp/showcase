# Methods and evidence boundaries

OpenSCAD MCP wrote and checked a self-contained parameter model and exported OFF parts. Blender MCP consumed the numeric vertices/faces with a 0.001 scale factor, then authored materials, lighting, objects and native keyframes. Three part-specific coordinate and topology hashes establish the CAD handoff. The validation records sampled wheel contact, carriage envelopes, gateway clearance, cargo placement and coupling endpoints.

Blender natively rendered the action sequence and stills. Delivery images received metadata-only path cleanup: the recorded compressed image payload and decoded pixels stayed identical. Four portable BLEND copies were saved through native operations, reopened with original sources unavailable and rendered against their individual reference images. Those byte identities are preserved in the new packages.

Kdenlive MCP produced the editorial timing and seven captions. Subsequent typed corrections qualified qimage PNG readers, portable relative references and the native dynamictext effect identity. All 480 headless accepted and relocated frames match. A distinct native GUI pass verified caption stacks, untouched Save Copy and reopening; its paired same-display exports match all RGB/RGBA frames and MP4 bytes. The original accepted film and the GUI comparison movie belong to different display environments and are not byte-identical to one another.

The final native project is unchanged: SHA-256 a77ec3142a18790b7602829ab2f73678470c954233a9272cd6ba07fb389afc9f. Its package filename is kdenlive/project.kdenlive; filename placement changes no project byte. The full archive preserves the referenced kdenlive/media/<sha256>.png layout. The compact archive deliberately omits those image dependencies and says so.

Public evidence is a curated projection of actual recorded results. It excludes raw logs, endpoints, machine identifiers, unreviewed runtime source and the old license declarations. Evidence binding hashes identify the original private records without revealing their paths. Packaging changes are limited to archive membership, documentation and manifests; original accepted archives remain preserved separately.

No model was imported from the creative-reference creators. No runtime, third-party asset library or font binary is shipped. Reproduction beyond opening these native documents requires compatible software and adapter capabilities; this batch is a media/source publication, not a software release. Parameter Undo, cross-machine pixel identity and continuous-time physics remain outside the qualified scope.
