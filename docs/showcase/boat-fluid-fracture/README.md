# A generated 17-part boat survives native geometry round trips; fluid fracture is still in progress

![Actual Mantra render of the assembled split boat, before accepted fluid destruction](split-assembled.jpg)

This draft follows a built-in imagegen reference through Hyper3D Rodin and Bang into Houdini. The portable split model contains 17 named parts and 150000 triangles with vertex UVs. Independent native acceptance preserved its geometry through HIP save/reopen and Bgeo export/reimport. A later importer patch recovered the packaged diffuse texture and scalar material settings. The final boat simulation, settled-fragment flotation and continuous final video remain unaccepted; this case is outside the selected collection.

## Generated source and native output

![Built-in imagegen reference; this is not a fluid simulation frame](boat-reference.jpg)

The reference is 1254 × 1254 pixels. Rodin generated the intact model using seed 4172, Gen-2.5-Medium, Raw triangle mesh, OBJ and PBR materials. Native import measured 500000 triangles. Bang then split that output using strength 7 and a target of 150000 faces. Native inspection measured 17 parts, 150000 triangles and vertex UVs. Generation settings and archive-member hashes are in the [model inventory](model-manifest.json). The split model is an assembled source for a destruction solve; its separate parts are not evidence that water broke the boat.

The [portable archive](source-model.zip) retains the split OBJ, five provider texture maps, relative material bindings and source notes. Its physical source units are unspecified. The native assembled preview used an explicit scale and placement, with measured metre bounds in [validation.json](validation.json). No watertightness or engineering hull certification is claimed.

## Reproduction

Extract [source-model.zip](source-model.zip), preserve its relative directory structure, and import `boat.obj` without merging named objects or dropping vertex UVs. [SOURCE.md](SOURCE.md) records the material-boundary fix, scalar conversion and maps that still need explicit destination shader setup. The independent geometry checks apply to this archive and its recorded hash. The native acceptance HIP and Bgeo stay private because their native metadata and source references are not cleared for redistribution.

The `replay/` directory contains the parameterized reconstruction used for the passing blank-scene, two-frame acceptance and reopened first-frame pixel comparison. Follow the [reproduction brief](reproduction-brief.md) and [acceptance requirements](acceptance-requirements.json); the complete recorded solve and its terminal metrics still need comparison. Reopening source geometry and matching initial physics frames do not accept a final boat simulation, and Bgeo conservation does not establish cross-application material parity. Final presentation media will derive from native Mantra EXRs with an explicit gamma 2.2 preview conversion; no denoising, filmic transform or ACES accuracy is claimed for that delivery plan.

## Boundaries

The intact stills, native source round trips, importer fix, cube calibration and independent two-frame rebuild are the accepted scopes in this snapshot. Final boat fracture, later fragment flotation, a complete simulation cache, a reopened final simulation, full-sequence independent rebuild, continuous final film, motion/audio review, bilingual browser playback and public deployment are unaccepted. Provider terms continue to govern generated artwork and assets; the repository software license supplies no additional artwork, training or evaluation-data permission. Image-generator model identity remains unknown.
